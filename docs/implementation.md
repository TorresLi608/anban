# 安伴实现说明

## 产品与界面

Flutter 应用「安伴」采用本地优先架构，Go 仅保存用户主动上传的加密照护快照。回忆媒体不进入服务器。
视觉：米白底色、森林绿主色、深灰文字；红色仅用于应急与逾时状态。首屏围绕今日用药、记录入口、陪护交接和待办。手机底部五个导航，宽屏侧边导航。
交互：页面轻淡入、记录表单从底部展开、打卡状态短暂过渡；尊重系统减少动画设置。

## 数据约定

- 本地：AES-256-GCM 加密，密钥存入系统安全存储，密文保存在 Sembast（Web 为 IndexedDB）。
- 备份：PBKDF2-HMAC-SHA256 / 210000 次迭代导出 256 位密钥，随机盐 16 字节、GCM nonce 12 字节。密码不存储、不发送服务器。
- 远端：单家庭实例、Bearer token 鉴权、If-Match 乐观并发检查、原子替换密文文件。主动同步覆盖照护快照前必须确认，保留本机回忆。
- 用药：仅录入已有医嘱，不计算或推荐剂量。固定计划和补救药分开；打卡包含实际时间和效果，重复打卡禁止。
- 媒体：单附件上限 20 MB；原始媒体导入后不删除。回忆附件不进入远端快照。

## 发布前仍需真实环境验证

Android/iOS 通知权限、精确闹钟、重启恢复、厂商省电策略、真机照片/录音/视频，以及应用签名。Web 仅用于预览与记录，不提供可靠后台用药闹钟；浏览器存储也可能被用户或系统清除。
护理条目是保守的通用照护信息，发布前应由具有资质的姑息照护团队审核。软件不作诊断，不调整药物，不将饮食偏方视为禁忌或治疗方案。
